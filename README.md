# BNK Team 2

## 🏦 예·적금 상품 소개·가입 및 관리 서비스

부산은행의 예·적금 상품을 소개하고, 고객이 비대면으로 계좌를 개설하여 금융상품에 가입할 수 있도록 구현한 **Web·Mobile 기반 금융 서비스 프로젝트**입니다.

## 📌 프로젝트 개요

* 부산은행의 예·적금 상품을 조회하고 가입할 수 있는 서비스를 구축했습니다.
* 서비스는 **Web과 Mobile 애플리케이션**으로 구성되어 있습니다.
* 사용자 권한은 **비회원, 회원, 사원 관리자, 상사 관리자**로 구분됩니다.
* Web에서 확인한 상품을 Mobile에서 바로 가입할 수 있도록 **QR코드와 Deep Link 기능**을 구현했습니다.
* RAG 기반 금융 상담 챗봇 **비니(Bini)**를 통해 예·적금 FAQ와 금융용어 관련 답변을 제공합니다.
* 상품 목록 페이지에서는 RAG를 활용한 **맞춤형 상품 추천, 상품 설명 및 상품 비교 기능**을 제공합니다.

## 💻 Web 서비스

* 예·적금 상품 목록 및 상세 정보 조회
* 회원가입 및 로그인
* 마이페이지를 통한 회원정보 및 가입상품 관리
* 상품 가입을 위한 QR코드 제공
* Deep Link를 활용한 Mobile 애플리케이션 연결
* RAG 기반 금융 상담 챗봇 **비니(Bini)** 제공
* 사용자 조건에 따른 맞춤형 예·적금 상품 추천
* 상품 정보 요약 및 설명
* 여러 금융상품의 주요 조건 비교

## 📱 Mobile 서비스

* 최초 1회 비대면 실명인증 및 입출금 계좌 개설
* 예·적금 상품 가입
* 상품 가입 진행 단계 및 가입상품 확인
* Web에 표시된 상품 QR코드를 스캔하여 해당 상품의 가입 화면으로 바로 이동

## 🤖 금융 상담 챗봇 비니(Bini)

**비니**는 Web 서비스에서 이용할 수 있는 RAG 기반 금융 상담 챗봇입니다.

사용자의 질문 의도를 분석하고, 오케스트레이션을 통해 질문에 적합한 RAG 파이프라인을 선택합니다. 이후 벡터 데이터베이스에서 관련 정보를 검색하고, 검색 결과를 바탕으로 답변을 생성합니다.

### 예·적금 FAQ RAG

* 예·적금 상품 및 서비스 이용과 관련된 FAQ를 검색합니다.
* 상품 가입, 해지, 이자, 만기 및 계좌 이용에 관한 질문에 답변합니다.
* 검색된 FAQ를 바탕으로 사용자의 질문에 적합한 답변을 생성합니다.

### 금융용어사전 RAG

* 사용자가 질문한 금융용어와 관련된 정보를 금융용어사전에서 검색합니다.
* 금융상품 이용 중 접할 수 있는 전문용어를 이해하기 쉽게 설명합니다.
* 검색된 용어의 정의와 관련 정보를 바탕으로 답변을 생성합니다.

```text
사용자 질문
    ↓
질문 의도 분석 및 오케스트레이션
    ↓
┌───────────────────┬────────────────────┐
│ 예·적금 FAQ RAG   │ 금융용어사전 RAG   │
└───────────────────┴────────────────────┘
    ↓
관련 문서 검색
    ↓
검색 결과를 기반으로 답변 생성
```

## ✨ 상품 탐색 RAG 서비스

상품 목록 페이지에서는 사용자가 자신에게 적합한 금융상품을 쉽게 찾고 이해할 수 있도록 RAG 기반의 상품 추천, 설명 및 비교 기능을 제공합니다.

### 맞춤형 상품 추천 RAG

* 사용자가 입력한 가입 목적과 조건을 분석합니다.
* 사용자 요구사항과 관련된 예·적금 상품 정보를 벡터 데이터베이스에서 검색합니다.
* 검색된 상품 중 사용자 조건에 적합한 상품을 추천합니다.
* 추천 결과와 함께 해당 상품을 추천한 이유를 제공합니다.

### 상품 설명 RAG

* 사용자가 상품명이나 상품에 관한 질문을 입력하면 관련 상품 정보를 검색합니다.
* 금리, 가입 기간, 가입 대상 및 우대 조건 등 상품의 주요 내용을 쉽게 설명합니다.
* 복잡한 상품 정보를 사용자가 이해하기 쉬운 형태로 요약하여 제공합니다.

### 상품 비교 RAG

* 사용자가 선택한 여러 예·적금 상품의 정보를 검색합니다.
* 금리, 가입 기간, 가입 금액 및 우대 조건 등 주요 항목을 비교합니다.
* 상품별 특징과 차이점을 요약하여 사용자의 상품 선택을 지원합니다.

```text
상품 탐색 요청
    ↓
요청 유형 분석
    ↓
┌──────────────────┬──────────────────┬──────────────────┐
│ 맞춤형 추천 RAG  │ 상품 설명 RAG    │ 상품 비교 RAG    │
└──────────────────┴──────────────────┴──────────────────┘
    ↓
관련 상품 데이터 검색
    ↓
추천·설명·비교 결과 생성
```

금융 상담 챗봇 **비니**가 예·적금 이용 및 금융용어와 관련된 일반적인 문의를 지원한다면, 상품 탐색 RAG 서비스는 상품 목록 페이지에서 사용자의 금융상품 탐색과 선택을 직접 지원하도록 분리하여 구현했습니다.
